#  一、项目工作流程

## 阶段1：明确需求分析和方案设计，预估对应测试方案与开发工具链（1周）

- **明确目标和需求**：
    - ARM型号（如ARM Cortex-M4的GD32F407**）
    - 测量范围（如 μA 到 A 级）、精度要求（如 ±1%）、采样率（如 1KHZ）。
    - 支持的ARM电压轨数量（如 Vcore, Vdd, Vmem）。
    - 接口类型（USB/UART/Ethernet/WiFi）。
    - 是否需要实时数据可视化或长时间数据存储。
- **明确开发工具链**：
    - **硬件设计**：KiCad（免费） / Altium Designer
    - **固件开发**：STM32CubeIDE + HAL库 / Zephyr RTOS，Clion
    - **测试工具**：
        - 电源负载：电子负载仪（ITech IT8700）
        - 数据可视化：Python + Matplotlib
        - 协议分析：Saleae逻辑分析仪
    - **开源替代方案**：
        - 参考项目：Nordic Power Profiler Kit II
        - 软件工具：PowerWise（TI）用于能耗分析
- **明确测试方案**：
    - **黑盒测试**：检测是否实现功能
    - **白盒测试**：根据目标和需求进行，检查功能是否存在bug。
- **关键组件选型**：
    - **ADC**：高精度、多通道ADC（如TI ADS131M08, ADI AD7177）。
    - **电流检测**：
        - 小电流：高边检流放大器（如TI INA219, MAX9929）。
        - 大电流：低阻值分流电阻 + 专用芯片（如TI INA226）。
    - **MCU**：带高速ADC的ARM Cortex-M（如GD32F407**）。
    - **隔离保护**：电压隔离（光耦/隔离ADC）和过压保护电路。
- **输出文档**：《需求规格说明书》、《测试时间安排表》

## 阶段2（预设）：硬件设计 (3-4周)

1. **原理图设计**：
    - 电流检测电路（分档设计：μA/mA/A量程）。
    - 电压测量分压电路（确保阻抗匹配）。
    - ADC与MCU的接口（SPI/I2C）。
    - 电源设计（LDO/开关电源，低噪声）。
    - 保护电路（TVS、保险丝、共模扼流圈）。
2. **PCB设计**：
    - 严格区分模拟/数字地（星型接地/磁珠隔离）。
    - 高精度ADC的布局（去耦电容靠近引脚、避免热源）。
    - 电流检测走线开尔文连接（Kelvin Connection）。
    - 4层板优先（完整地平面）。
3. **设计评审**：检查信号完整性、热设计、EMC预兼容性。

## 阶段3（预设）：PCB制造与焊接 (2周)

- **PCB制板**：选择高速板材（如FR4 TG170），注意阻抗控制。
- **元件采购**：关键器件（ADC、检流放大器）预留样品余量。
- **焊接与检测**：
    - 优先焊接电源部分，验证供电稳定性。
    - 检查虚焊/短路（显微镜/X-Ray）。

## 阶段4（工作核心）：固件开发 (3-4周)

### 1、固件核心任务分解

#### **（1） 底层驱动（1.5人周）**：

- **ADC配置**
    - 初始化SPI/I2C接口（0.5天）
    - 设置采样率、增益、滤波器（e.g. AD7177的SINC5+FIR配置）（1天）
    - 多通道轮询模式/DMA传输（需处理数据对齐问题）（1.5天）
- **电流检测芯片控制**（如INA226）
    - I²C配置、校准寄存器设置（量程/精度）（0.5天）
- **通信接口**
    - USB-CDC虚拟串口（CubeMX自动生成 + 调试）（1天）
    - UART命令解析框架（中断/DMA接收）（0.5天）

#### （2）**数据采集与处理**（1人周）

- **实时数据流处理**

    - ADC原始值 → 电压/电流计算（需校准系数）（0.5天）
        $$
        V_{real} = \text{ADC}_{raw} \times \frac{V_{ref}}{2^N} \times K_{calib}
        $$

    - 功率积分算法：$E = \sum (V_n \times I_n \times \Delta t)$（注意防止累加溢出）（1天）

- **多量程自动切换**

    - 动态判断电流范围 → 切换检流放大器增益（需防振荡）（1天）

- **数据缓存**

    - 双缓冲DMA + 环形队列（防止高速采样丢失数据）（0.5天）

#### （3） **校准与补偿**（0.5人周）

- **温度补偿**
    - 读取温度传感器（如I²C的LM75）（0.5天）
    - ADC零漂/增益的温度曲线拟合（查表法/线性补偿）（1天）
- **非线性校正**
    - 存储3点校准参数（零点/满量程/中点）至Flash（0.5天）

#### （4）**通信协议与上位机交互**（0.5人周）

- **二进制协议设计**（示例帧结构）：

    ```
    [0xAA][0x55][CMD][LEN][DATA...][CRC16]  
    ```

    - 支持命令：开始采样、设置采样率、读取校准值等（1天）

- **数据流模式**

    - 定时打包发送（避免USB小包效率问题）（0.5天）

#### （5） **系统管理与安全**（0.5人周）

- **看门狗与异常复位**（独立看门狗IWDG配置）（0.2天）
- **过载保护**
    - 实时检测电压/电流超限 → 触发硬件关断（通过GPIO控制MOSFET）（0.3天）
- **固件升级**
    - Bootloader开发（USB/UART的YMODEM协议）（可选，+1人周）

### 3、关键时间影响因素

1. **硬件依赖延迟**（风险极高！）
    - 若ADC电源噪声大/布局不合理，固件需增加软件滤波（中值滤波+均值滤波），**+3~5天**
    - 电流检测范围切换时的硬件振荡（需加RC滤波），**+2天调试**
2. **算法复杂度**
    - 需实时计算FFT分析功耗频谱？ → **+1人周**
    - 多通道同步采样（严格相位对齐）：**+2天**
3. **通信可靠性**
    - 增加TCP/IP（如W5500）需移植LwIP协议栈：**+1.5人周**
4. **校准流程**
    - 全温度范围校准（-40℃~85℃）：**+3天实验室时间**

### 4、加速开发建议

1. **复用成熟代码**
    - 使用STM32CubeMX生成基础驱动（ADC/USB）
    - 移植开源嵌入式协议栈（如[Protocol Buffers for Embedded](https://github.com/protobuf-c/protobuf-c)）
2. **模块化调试**
    - 先验证单通道采集 → 再扩展多通道
    - 用J-Scope实时监控变量（避免依赖串口打印）

### 5、典型问题与应对

| **问题现象**         | **原因分析**           | **解决方案**              | **时间损失** |
| :------------------- | :--------------------- | :------------------------ | :----------- |
| ADC读数周期性跳变    | 电源纹波（>50mV）      | 增加LC滤波电路            | 3天          |
| 多量程切换时数据异常 | 放大器建立时间不足     | 切换后延迟5ms再采样       | 1天          |
| USB传输丢包          | 无流控机制             | 添加XON/XOFF软件流控      | 0.5天        |
| 功率积分结果漂移     | Δt取自系统时钟（不准） | 改用ADC内部定时器触发采样 | 1天          |

------

**总结**：固件开发**核心耗时**在于**ADC稳定性调试**（30%时间）和**动态精度优化**（40%时间）。建议预留总时间的20%作为风险缓冲，优先实现基础采集功能，再逐步增加高级特性。若团队有成熟驱动积累，可压缩至**2.5人周**完成。

## 阶段5：系统集成与测试 (3-4周)

- **功能测试**：
    - 静态精度：用高精度源表（如Keithley 2450）标定。
    - 动态响应：负载跳变测试（0-100mA阶跃）。
- **系统验证**：
    - 连接ARM开发板，对比商用功率计（如Keysight N6705C）。
    - 长期稳定性测试（24小时连续采集）。
- **问题修复**：调整滤波参数、优化PCB布局、升级固件逻辑。
- **回归测试**：基于修复的问题进行回归测试。

## 阶段6：文档与优化 (1周)

- **用户文档**：接线图、API说明、校准流程。
- **开源部署**（可选）：
    - 发布硬件设计（KiCad项目）。
    - 固件上传（GitHub托管）。
    - 上位机工具（Python/PyQt示例）。

# 三、关键注意事

1. **精度保障**：
    - 电流检测电阻选低温漂（±10ppm/℃）材质（如锰铜合金）。
    - 校准环节不可省略（多点拟合补偿非线性误差）。
2. **抗干扰设计**：
    - ADC基准电压用专用Ref芯片（如REF5025）。
    - 模拟输入走线包裹地线，避免并行数字信号。
3. **安全设计**：
    - 输入端口加自恢复保险丝（PPTC）。
    - 电压测量通道用高压电阻分压（如1206封装耐压200V）。
4. **扩展性预留**：
    - 留出I²C扩展口（可接温度传感器）。
    - 固件支持OTA升级（预留Bootloader空间）。
